# 平台访问限制

内置 39 个平台配置提供 216 项读取和 4 项操作契约。登记某项能力不表示学校所有账号都有访问权限，也不表示该平台所有业务已经逐项核验。

- 实时入口和当前权限通过 `ruc_platforms(live=true)` 获取，不随公开仓库发布开发账号目录。
- 独立账号、未同步账号、院系或教职工权限拒绝，由对应平台管理员或账号持有人处理；不自动重试密码、切换身份或注册。
- 学校认证配置、内网连通性、HTTPS 跳转和外部服务协议可能需要进一步适配。保留实际错误，不将失败解释为空数据。
- 社科数据当前仅匿名读取，首次登录可能注册；未来课堂需要绑定时返回明确错误。注册、绑定都不作为只读开发验证。
- 哲学院会议室读取不代表具有预约权限，官网按院系身份判断。党校读取不产生学习打卡或登记学时。
- 未来课堂和党校的复杂认证已通过 HTTP 契约验收，浏览器端认证尚未验收。
- 四项写契约从前端协议核对并做离线测试，未在真实平台执行。实际任务需由用户具体授权。

平台字段改变时修改 JSON 契约；认证协议改变时修改对应适配器。参数、已核验范围和来源通过 `ruc_capabilities` 取得。
