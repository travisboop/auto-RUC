# 版本进度

## 0.4.0 · 2026-11-27

公开版本内置 39 个平台配置、220 项能力：216 项读取和 4 项操作契约。新增 200 项读取有授权测试账号的实际核验，原有 16 项保留此前验证；全新 MCP 验收覆盖各配置的读取或实时门户发现。部分时段或辅助浏览器请求返回 partial，结果保持实际范围。

普通接口使用 JSON 契约，共用认证、分页、响应检查和字段保留；CLI、JSONL、MCP、Python 使用相同运行时。支持公开读取、CAS、微人大、多级认证、前端/API 分域和一次性登录交换。未来课堂和党校使用小型认证适配器，业务继续由契约描述。

浏览器按精确请求语义控制读取；动态注册会刷新匿名认证策略。操作使用预览、冻结参数和单次提交。真实业务写入为 0 次。

公开副本省略账号目录、个人查询、访问拒绝详情及历史抓取文件。离线入口搜索在没有历史快照时使用已登记平台，不依赖私有资料。
