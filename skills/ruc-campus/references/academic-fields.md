# 教务字段解释

适用于本包 `grades`、`rankings`。字段标签已于 2026-11-25 对照教务当前前端核实。按下述口径即可解释正常返回；规则与返回不一致时再核查官网。

## 单门课程绩点

只在 `grades.records` 的 `rowType=course` 中匹配课程。官网名称可能使用罗马数字，如 `Ⅱ`，用户可能写“二”或“2”；先找课程名称主体，再确认序号和学期。存在多次修读时分别列出，不擅自选一条。

| 字段 | 含义 |
|---|---|
| `kcname` | 官网课程名 |
| `zcjname1` | 最终成绩显示值 |
| `xf` | 课程学分 |
| `jd` | **课程学分绩点**，即课程绩点乘以课程学分 |
| `cjbzname/ksxzname` | 成绩标志、考试性质 |
| `pjxfjd` | 学校给出的平均学分绩点；不作为某门课的绩点 |

用户问一门课的“绩点”时，给出普通四分制课程绩点。对 `xf>0`、`jd` 为有效数值的课程行，可用 `jd / xf` 换算，并按成绩核对下表。使用 `Decimal` 避免浮点尾差。回答标明四分制；必要时同时列出成绩、学分和学分绩点原值。

例如虚构课程甲：84 分、3 学分、`jd=9.9`，课程绩点为 `9.9 / 3 = 3.3`，与成绩区间一致。不要把加权后的 `9.9` 当作四分制绩点。

依据学校《本科课程成绩管理办法》校政字〔2024〕56 号第六条：

| 百分制 | 等级制 | 课程绩点 |
|---|---|---|
| 90–100 | A | 4.0 |
| 86–89 | A- | 3.7 |
| 83–85 | B+ | 3.3 |
| 80–82 | B | 3.0 |
| 76–79 | B- | 2.7 |
| 73–75 | C+ | 2.3 |
| 70–72 | C | 2.0 |
| 66–69 | C- | 1.7 |
| 63–65 | D+ | 1.3 |
| 60–62 | D | 1.0 |
| 60 以下 | F | 0 |

合格制 P 对应 1.0，F 对应 0，不能把 P 解释为 A。若缺失学分或绩点、换算超出 0–4、与成绩规则不一致，保留原值并说明该项待核对，不自行改写。

官方依据：[成绩管理办法，第六条，PDF 第 3 页](https://jiaowu.ruc.edu.cn/docs/2024-09/56ac118592634b2fbba1b1526b96919d.pdf#page=3)；[`jd` 的当前前端标签](https://jw.ruc.edu.cn/Njw2017/student/course-score-search/course.score.search.js)。这里解释单课字段，不用课程列表自行推算学校官方排名或替代学校 GPA。

## 累计排名

用户问“总排名”且未指定学期时，调用 `rankings` 并省略 `term`。接口由学校按全部可用学期计算；核对结果 `xnxq` 后说明具体范围，不能说成全校所有学生的排名。

| 字段 | 含义 |
|---|---|
| `xnxq` | 学校返回的统计学期/学年范围，例如“全部学年” |
| `pm` | 专业排名 |
| `bjpm` | 班级排名 |
| `pjxfjd` | 学校计算的平均学分绩点 |
| `sdxf` | 实得总学分 |
| `zjd` | 总学分绩点 |
| `countnum` | **总门数（课程数）**，不是参与排名的人数 |

直接报告 `pm` 和 `bjpm`。接口未给排名人数时不添加分母，不把总门数写成“第几 / 几人”。字段标签来源：[当前排名页面前端](https://jw.ruc.edu.cn/Njw2017/student/student-professional-ranking-query/student.professional.ranking.query.js)。
